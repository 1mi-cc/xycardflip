Card Flip Assistant - First Start Guide

1. Open .env in the same folder as CardFlipAssistant.exe.
2. Keep API_HOST=127.0.0.1 and SQLITE_PATH=./data/trading.db for local desktop usage.
3. Set UI_AUTH_PASSWORD before first use, or leave it empty and let the app generate a one-time bootstrap password.
4. If UI_AUTH_PASSWORD is empty, read the generated password from .\data\bootstrap_admin_credentials.json after first launch.
5. Keep UI_AUTH_USERNAME and UI_AUTH_NICKNAME as desired for your local operator account.
6. If you do not use external services, keep GEMINI_API_KEY, RAGFLOW_API_KEY and SUPABASE_SERVICE_ROLE_KEY empty.
7. Auto-tune defaults are safe-off. Only set AUTO_TUNE_AUTO_APPLY_ENABLED=true after you understand the cooldown and sample guard variables.
8. Start the software with start_card_flip_app.bat.

Packaged release defaults:
- UI_AUTH_USERNAME=admin
- UI_AUTH_PASSWORD=
- AUTO_TUNE_AUTO_APPLY_ENABLED=false
- AUTO_TUNE_COOLDOWN_HOURS=24
- AUTO_TUNE_MIN_CLOSED_BATCHES=2

Do not share the generated bootstrap credential file with other users.
